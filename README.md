# Правила Discord-сервера

Публичный справочник: 65 пункт с пояснениями и примерами, поиск, разделы, печать и прямые ссылки.

## Как изменить правила

1. Откройте `index.html` в этом репозитории.
2. Нажмите кнопку редактирования (карандаш).
3. Найдите нужный номер правила, например `1.1A`.
4. Измените заголовок, основной текст, пояснение, пример или наказание. Сохраните HTML-теги вокруг текста.
5. Нажмите **Commit changes** и сохраните изменения в ветку `main`.
6. Дождитесь завершения публикации в разделе **Actions**. Сайт обновится по прежней ссылке.

Всё оформление и поведение находятся в `index.html`; сборка и установка зависимостей не нужны. Поиск использует актуальный текст страницы, поэтому отдельно обновлять поисковый индекс не требуется.

Сохраняйте существующие `id="rule-…"`, чтобы ранее отправленные ссылки на пункты продолжали работать. При добавлении пункта скопируйте целиком соседний `<article>`, задайте уникальный ID, номер и `data-link` кнопки. Счётчики правил и разделов обновляются автоматически.

## Доступ и история изменений

Сайт читают все без входа в GitHub. Изменять исходники может владелец репозитория и назначенные им участники с правом записи. Посторонние могут предлагать изменения через pull request, но не публиковать их самостоятельно. История изменений хранится в Git; при необходимости старую версию можно восстановить.

## Публикация

GitHub Pages: ветка `main`, каталог `/ (root)`. Включён HTTPS. Файл `.nojekyll` отключает обработку Jekyll.

Доступность из конкретной сети зависит от доступа к GitHub Pages; сайт не требует API, сторонних шрифтов, аналитики или внешних библиотек.

## Редакция 1.1: объединение повторов

Из 131 пункта осталось 65: 66 дублирующих формулировок включены в общие пункты. Номера сохранены, поэтому пропуски нормальны. Старые ссылки и поиск по старым номерам автоматически ведут к объединённым правилам. Таблица соответствий — в `MIGRATION.md`.
